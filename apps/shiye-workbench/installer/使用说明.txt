拾页工作台 2.2.2 · Windows 安装版

安装与打开
双击安装程序，按向导完成安装。程序会自动创建桌面快捷方式和开始菜单入口。
以后双击桌面「拾页工作台」即可打开，不需要每次运行安装程序。
默认仅为当前 Windows 用户安装，不需要管理员权限。
默认安装目录：%LOCALAPPDATA%\Programs\ShiyeWorkbench

首次使用
无需安装 Python 或 Node.js。软件界面使用本机 Microsoft Edge WebView2 Runtime；缺少时请先从微软官网安装。
实际采集需要本机 Chrome 或 Edge。打开登录浏览器，由使用者本人登录小红书，再创建采集任务。
支持原有采集、筛选、词库、Excel / CSV / JSON 导出、备份、收藏和备注功能。
每个人使用独立的本地数据库和登录状态，安装包不含个人采集数据或登录资料。

更新与卸载
更新前先退出程序，再运行新安装包。重复安装会使用已记录的安装目录并刷新快捷方式。
工作区保存在安装目录内，更新不会覆盖 data、采集结果、备份等用户文件。
可在 Windows「设置 → 应用 → 已安装的应用」中卸载拾页工作台。
卸载只删除程序文件、快捷方式和卸载入口，保留采集数据、词库、设置、备份和登录资料。
如需恢复使用，重新安装到原目录即可读取保留的数据。

已有便携版数据
请先在旧版备份并退出。安装版首次使用是独立的空工作区，不会自动搬走旧版本的数据。
如需迁移，先退出所有版本，把旧工作区的 data、采集结果、备份及浏览器资料目录整体复制到安装目录，保留原文件夹作为备份。
同一个工作区不能被两个程序同时打开。

第三方许可
安装目录「第三方许可」包含应用依赖和安装器的许可文本；应用内「使用帮助 → 第三方许可」也可查看内置依赖许可。
安装器由官方 NSIS 3.12 编译：https://nsis.sourceforge.io/Download
当前安装包与主程序均未做代码签名。
